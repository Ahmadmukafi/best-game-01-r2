Ember & Anvil is an original 2D canvas forge-master arcade game: five days, one forge — heat every order in the bellows, strike it on the anvil, quench it in the barrel, and get paid for quality, from a humble Horseshoe to the Crown of Embers on day 5.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8123/ in a desktop browser. No build step, no network requests — the game is static files under game/.
